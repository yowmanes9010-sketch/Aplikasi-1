# Amadeus Absensi

Aplikasi pengguna. Upload folder ini ke hosting static/HTTPS setelah `config.js` diubah menjadi URL backend online.

Alur:
Login/Daftar → izinkan kamera → izinkan GPS → selfie → server memvalidasi radius dan mencatat waktu server → hasil langsung muncul di dashboard admin.

Jangan menaruh ADMIN_KEY di aplikasi ini.
